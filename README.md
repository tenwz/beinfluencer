## 为什么叫这个名字

正确的英语是 **be an influencer**。这个项目名偏偏少写了那个冠词 —— 因为在线上，「influencer」不是一个需要认证头衔的身份，而是一个动作：

**去成为。** 不用等平台给你加 V，不用等别人同意，账号开出来，就可以开始。

所以名字是 `beinfluencer`，slogan 里再把冠词补回去，当作提醒：*you have to be, then become an influencer.*

## 想解决什么

线上从来不缺账号，缺的是被看见的理由。

一个新号、一个小号、一个企业号，发出去的内容和几千万条其他内容挤在同一个信息流里 —— 平台不关心你是谁，只关心内容能不能留住人。真正卡住大多数人的不是「不会发」，而是：

- **不知道对谁说**：定位没想清楚，内容就没有主线
- **不知道怎么被分发**：不同平台的算法、内容形态、节奏完全不同
- **无法持续**：靠灵感产出，三周之后断更

beinfluencer 想做的，是把「一个陌生账号从 0 到被记住」这件事变成一套可以执行的流程 —— 不管这个账号属于谁，也不管放在哪个平台。

## 大致思路

| 阶段 | 要回答的问题 | 产出 |
| --- | --- | --- |
| 定位 | 这个账号代表谁、为谁说话、凭什么被记住 | 人设与内容主线 |
| 内容 | 哪些选题值得做，用什么形态承载 | 选题库与内容模板 |
| 分发 | 这个平台的算法奖励什么 | 发布节奏与平台适配 |
| 复盘 | 什么内容真的有效，为什么 | 数据反馈与下一轮迭代 |

目标形态是：**输入一个账号和一个平台，输出一套能持续跑的内容策略与执行方案。**

> 以上是方向，不是已完成的功能。仓库目前处于初始化阶段。
